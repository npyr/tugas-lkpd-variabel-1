🌊 Aktivitas 1 - Prediksi

let a = 10;
let b = 5;
console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
Operasi Prediksi Hasil Sebenarnya
a + b 15 15
a - b 5 5
a * b 50 50
a / b 2 2
Apakah prediksi kamu benar? ✓ Ya Sebagian / Tidak
Mengapa? Karena operasi matematika dasar dalam JavaScript berjalan sesuai standar aturan aritmatika penjumlahan (+), pengurangan (-), perkalian (*), dan pembagian (/).

🧪 Aktivitas 2 - Eksperimen

let a = 20;
let b = 4;
console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
console.log(a % b);
Prediksi:
a + b = 24 | a - b = 16 | a * b = 80 | a / b = 5 | a % b = 0
Apa yang kamu temukan?
Operator % (modulo) digunakan untuk mendapatkan sisa hasil bagi. Karena 20 dibagi 4 hasilnya tepat 5 tanpa sisa, maka 20 % 4 menghasilkan 0.

💬 Aktivitas 3 - Input dengan prompt()

let nama = prompt("Masukkan nama:");
console.log(nama);
let umur = prompt("Masukkan umur:");
console.log(umur);
Apa fungsi prompt()?
Fungsi prompt() berguna untuk menampilkan dialog box interaktif yang meminta input berupa teks dari pengguna, lalu menyimpan teks yang diketikkan ke dalam variabel.

⏳ Aktivitas 4 - Menghitung Umur

let tahunLahir = prompt("Masukkan tahun lahir:");
let tahunSekarang = 2026;
let umur = tahunSekarang - tahunLahir;
console.log(umur);
Uji dengan tahun lahir kamu:
Uji coba misal tahun lahir 2010: Umur = 16 tahun (2026 - 2010).

🛒 Aktivitas 5 - Mesin Kasir Mini

let harga = prompt("Masukkan harga:");
let jumlah = prompt("Masukkan jumlah:");
let total = harga * jumlah;
console.log(total);
Uji: Harga = 5000, Jumlah = 4
Total = Rp 20.000 (5000 * 4).

🤝 Aktivitas 6 - Think Pair Share

THINK: Mengapa membutuhkan variabel total?
Agar nilai perhitungan (harga * jumlah) tersimpan rapi di memori sehingga dapat digunakan kembali atau ditampilkan berulang kali tanpa perlu menghitung ulang dari awal.
PAIR: Jawaban sama? ✓ Ya / Tidak
SHARE: Kesimpulan kelompok:
Penggunaan variabel penampung seperti total membuat struktur penulisan kode lebih efisien, bersih, serta mudah dalam proses debugging maupun pengembangan program.

🏪 Aktivitas 7 - Challenge: Warung Digital

Program dasar Warung Digital:

let makanan = prompt("Nama makanan:");
let harga = Number(prompt("Harga:"));
let jumlah = Number(prompt("Jumlah:"));
let total = harga * jumlah;

console.log("Makanan:", makanan);
console.log("Harga:", harga);
console.log("Jumlah:", jumlah);
console.log("Total:", total);

Pengembangan dengan Diskon 10%:

let diskon = total * (10 / 100);
let bayar = total - diskon;

console.log("Total:", total);
console.log("Diskon (10%):", diskon);
console.log("Total Bayar:", bayar);

🐞 Aktivitas 8 - Debugging

Kode Awal (Error):

let harga = 5000;
let jumlah = 3;
let total = harga harga; // Error sintaks / perkalian hilang
console.log(total harga); // Error sintaks penulisan
Kesalahan:
  1. Baris perhitungan let total = harga harga; kekurangan operator perkalian * dan salah menyebutkan variabel jumlah.
  2. Baris output console.log(total harga); kekurangan tanda koma , atau pemisah argumen.

Perbaikan Kode:

let harga = 5000;
let jumlah = 3;
let total = harga * jumlah;
console.log(total);

💰 Aktivitas 9 - Challenge Mandiri: Kalkulator Tabungan

Program menghitung total tabungan:

let uangAwal = Number(prompt("Masukkan uang awal:"));
let hari1 = Number(prompt("Tabungan hari pertama:"));
let hari2 = Number(prompt("Tabungan hari kedua:"));
let hari3 = Number(prompt("Tabungan hari ketiga:"));

let totalTabungan = uangAwal + hari1 + hari2 + hari3;
console.log("Total tabungan = Rp" + totalTabungan);
Output Contoh: Total tabungan = Rp [Hasil Penjumlahan]

📖 C. Rangkuman Bahan Ajar

  • Variable: Tempat menyimpan data (contoh: let nama = "Budi";).
  • Alur Program: INPUT → PROCESS → OUTPUT.
  • prompt(): Menerima input teks. Ubah ke angka menggunakan Number().
  • Operator Aritmatika: + (tambah), - (kurang), * (kali), / (bagi), % (modulo/sisa bagi).
